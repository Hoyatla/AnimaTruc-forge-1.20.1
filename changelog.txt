v1.0.0-proprietary.4 (AnimaTruc)
- Add unified `animatruc-pack` workflow (model + animations in one runtime pack file).
- Add model geometry payload in core assets:
  - `ModelGeometry`
  - `ModelCube`
  - `AnimationAssetPack` now carries geometry + skeleton + clips
- Add importer route upgrades:
  - new extension support: `.animatrucpack`, `.animatrucpack.json`
  - source-name based importer entrypoint (`importFromString`) for runtime/resource loading
- Upgrade Blockbench plugin to V2 (`blockbench-plugin/animatruc_exporter.js`):
  - native open/import shortcuts for `.bbmodel` and `.gltf`
  - project validation action
  - pack preview action
  - unified runtime pack export (`.animatrucpack.json`)
- Add Forge runtime loader + example bootstrap:
  - `AnimaTrucForgePackLoader`
  - `AnimaTrucExampleBootstrap`
  - shipped example pack resource under `assets/animatruc/animatrucpacks`
- Add E2E test proof:
  - plugin-exported pack fixture imported through runtime importer with assertions

v1.0.0-proprietary.3 (AnimaTruc)
- Add dedicated AnimaTruc JSON importer (`.animatruc.json`, `.animatruc`) in core runtime.
- Add direct import route in `AnimationAssetImporters` for AnimaTruc pack files.
- Add Blockbench plugin in repository:
  - `blockbench-plugin/animatruc_exporter.js`
  - export action for direct AnimaTruc pack generation
  - validation action for channels/bones consistency
- Add importer regression tests for AnimaTruc pack format and route resolution.
- Add Blockbench plugin usage guide in `blockbench-plugin/README.md`.

v1.0.0-proprietary.2 (AnimaTruc)
- Add asset model import API with stable pack output (`AnimationAssetPack`).
- Add skeleton representation (`ModelSkeleton`, `ModelBone`) for authoring pipeline.
- Add Blockbench importer:
  - parse outliner/bones hierarchy
  - parse animation channels (position/rotation/scale)
  - convert keyframes to AnimaTruc runtime clips
- Add glTF JSON importer:
  - parse nodes and parent hierarchy
  - parse animation samplers/channels
  - decode FLOAT accessors from embedded or external buffers
  - convert translation/rotation/scale tracks to AnimaTruc clips
- Add extension-based importer facade (`AnimationAssetImporters`) for `.bbmodel` and `.gltf`.
- Add regression tests for bbmodel import, gltf import, and importer routing.

v1.0.0-proprietary.1 (AnimaTruc)
- Add layered animation system with per-layer weighting and per-bone masks.
- Add animation graph runtime:
  - immutable graph definition builder
  - state transitions with conditions and priorities
  - cross-fade windows between active states
- Add procedural modifier pipeline:
  - look-at rotation modifier
  - breathing micro-motion modifier
  - two-bone IK modifier (planar XY)
- Add runtime profiler for graph/mix/modifier/total frame timings.
- Extend animator context to carry look targets and scalar parameters.
- Extend math and transform primitives for procedural runtime use.
- Add regression tests for graph transitions, layer masking, and modifiers.
